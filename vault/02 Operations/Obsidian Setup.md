# Obsidian Setup — lean first

The vault works without community plugins. Install only the plugins that solve a real job, one at a time, and back up the vault before changing theme or metadata behaviour.

## Recommended order

1. Dataview — core. It turns frontmatter into project, decision, and feature dashboards.
2. Folder Notes — core. It gives each folder a human landing page.
3. Omnisearch — core for human retrieval; it can rank notes and optionally index documents/images through Text Extractor.
4. Local Backup — only after choosing an external/output path and retention policy. Exclude assets, videos, node_modules, .git, and trash unless intentionally archived.
5. Callout Manager — optional, for consistent WARNING, DECISION, TESTED, and NEEDS OWNER callouts.
6. Columns, Editing Toolbar, Iconize — optional presentation/editing tools. They do not improve AI accuracy.

## Do not use by default

Style Settings redirects to a community-archive repository. Do not install it in the first setup. Use built-in Obsidian theme settings and CSS only if a maintained dependency and an actual styling need are identified.

## Relationship to LihFolk

LihFolk V2 ships its own Obsidian presentation and needs no community plugins for its core vault. Keep it as a separate vault. This studio vault links to it as an evidence library; it does not merge or duplicate it. That protects its update path, licence, and search tooling.

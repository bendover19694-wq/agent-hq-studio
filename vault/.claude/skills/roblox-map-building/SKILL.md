# Roblox map building

Use the complete procedure in ../../../03 Skills/Map Building.md relative to this skill directory when it is accessible. Use Study -> Blockout -> Playtest -> Build -> Detail -> Optimize -> Test Again.

Study references and define scale, loops, landmarks, interiors, routes, elevation, sightlines, combat/traversal space, and each area's purpose. Reject empty space, fake doors, repetitive halls, generic boxes, and purposeless clutter. Build readable density through useful interiors, routes, verticality, landmarks, and environmental storytelling.

Playtest collision, camera, movement, mobile readability, performance, clipping, floating props, AI navigation where applicable, spawn safety, and route quality. Batch related edits and report the observed result once.

# Storage preflight

Use ../../../02 Operations/Capability and Storage Preflight.md and ../../../03 Skills/Storage Preflight.md relative to this skill directory when they are accessible.

Run read-only free-space and candidate-location checks first. Report only safe metadata: exact path, size, dates, likely purpose, activity risk, expected reclaim, and recovery path. Do not read or expose secret contents. Never delete, uninstall, or move anything until the owner approves exact numbered targets. Confirm the project/tool still works after an approved cleanup.

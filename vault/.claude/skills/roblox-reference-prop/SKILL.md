# Reference prop modelling

Use the complete procedure in ../../../03 Skills/Reference Prop Modelling.md relative to this skill directory when it is accessible. Confirm the owner has rights to the reference. Do not invent/stylise when fidelity is requested.

Level/mirror the side image, create pixel-grid crops, trace every real component/cut-out/curve/pivot, construct separate moving pieces in headless Blender, project approved reference colour data, and compare a CPU/Workbench side preview against the source at matching width. Iterate before handoff.

Report permissions/source, mesh/pivot grouping, triangle budgets, material/texture use, comparison image, Studio import validation, and outstanding owner choices.

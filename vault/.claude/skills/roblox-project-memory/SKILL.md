# Project memory

Use the complete procedure in ../../../03 Skills/Project Memory.md relative to this skill directory when it is accessible. Read the system note before changing a system and update it when observed reality changes.

Use concise metadata and record purpose, dependencies, owned files/instances, contracts, locked decisions, references, test evidence, defects, rollback/recovery, and the next smallest action. Write facts and observed results, not a chat transcript. Mark source quality and verify uncertain/current claims.

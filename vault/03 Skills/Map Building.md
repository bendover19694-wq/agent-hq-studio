# Map Building

## Required flow

Study -> Blockout -> Playtest -> Build -> Detail -> Optimize -> Test Again.

Before placing assets, inspect the reference and name the map's scale, layout, architecture, landmarks, elevation, interiors, routes, combat spaces, traversal, sightlines, and learning path. Write a compact map brief and acceptance checklist.

## Make every space earn its place

Every major area needs a gameplay purpose and a memorable landmark. Add useful interiors, shortcuts, alternate routes, rooftops, stairs, alleys, vertical paths, hidden spaces, readable entrances, logical storage/staff/back routes, and environmental storytelling.

Do not solve a map with random box buildings, giant empty areas, useless rooms, repetitive corridors, fake doors, or random props posing as detail. A door should lead somewhere or not exist. Density should create decisions, discovery, cover, and story.

## Test, do not admire from Edit mode

Play the intended loop. Check collision, scale, lighting, AI navigation when applicable, player movement, camera, mobile visibility, performance, clipping, floating props, spawn safety, routes, shortcuts, and sightline abuse. If it is boring, change the layout. If it feels generic, sharpen the identity. If it is empty, add meaningful density. If it is cluttered, remove noise.

Batch connected map changes, test once, fix, improve, and report once. Do not repeatedly scan unchanged files or narrate the same plan.
